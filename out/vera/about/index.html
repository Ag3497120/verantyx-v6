Vera · 初期版

Vera — 嘘をつけない枠をつくる AI

答えられることには出所を付けて答え、答えられないことには型を付けて黙る。その枠を、言語モデルやエージェントの外側に置くための AI です。

  • 重みがない
    学習した重みを持たず、規則と記録で動きます。学習で外れることがありません。
  • 遅延のない判断
    CPU の上で、ミリ秒の単位で判断します。
  • 出所か、型つきの沈黙か
    答えには必ず出所が付きます。分からなければ、何が欠けているかを型で示して黙ります。
  • 記憶は追記のみ
    記憶は書き足すだけ。単位で削除でき、昇格には人の同意が要ります。
体験するオープンソース
できること

Vera だからできること

(a)LLM の答えの検証器

答えの根拠を「人の記録にある」「生成だけ」「不明」に分けます。生成だけで事実を答えることはしません。

(b)生成の前段の門

入力を構造に読み、読めないもの・読みが割れるものは通しません。規則と記録で動くので、学習で外せません。

(c)エージェントの判断の台帳

人の決定を人の記録として持ちます。エージェントの申告は申告のまま残し、記録への昇格には同意が要ります。

(d)構造化された記録への決定的な QA

名簿・作業記録・ログに対して、誰が・何を・いつ・どこへ を決定的に答えます。

ソースは GitHub で公開しています。文書を渡して、対話または一問ずつ聞けます。

github.com/Ag3497120/vera →

# 対話
python -m verantyx.cli chat --mode round5 --document <ファイル>

# 一問だけ
python -m verantyx.cli ask --mode round5 --document <ファイル> -- <問い>

# パッケージを導入していれば vera コマンドでも
vera chat --mode round5 --document <ファイル>

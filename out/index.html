Wine を使わない、Windows ランタイム

vxrt（VXRuntime）は Apple silicon の Mac のためにゼロから書いた Windows 互換層です。Windows のプログラムを読み込み、呼ばれた API を macOS の機能で直接実装します。2026 年 10 月 12 日に書き始めました。Wine では CPU が詰まり 30 fps 前後で止まっていたからです。

すべての層が手の中にあるので、シェーダの翻訳ひとつまで直せます。フェンスや草が一色に光る不具合も、定数バッファの読み方を Direct3D に合わせて直しました。

まだないもの: Direct3D 12、Vulkan、テッセレーション。アンチチートの回避は行いません。

  • Direct3D 11 / DXGI → Metal動作

    DXBC から Metal Shading Language への翻訳器。境界外の読み取りも Direct3D と同じく 0 を返す

  • PE ローダー動作

    Windows の実行ファイルと DLL を読み込み、つなぐ

  • ファイル・レジストリ動作

    macOS のファイルシステムの上に

  • スレッド・同期・例外動作

    Mono や Unity の GC が使う一時停止まで

  • ウィンドウ・入力動作

    AppKit の上に

  • ソケット・COM動作

    ゲームが Mac の Steam クライアントにつながる

  • オーディオ動作

    Core Audio の上に。ヘッドセットへはプロセスタップで

  • x86 → ARM64 翻訳器開発中

    Rosetta 2 の代わりの自前の翻訳器。The Lab が 52.7〜56.4 fps（Rosetta は 59.4〜59.6）。まだ安定していない

  • ↓ macOS（Metal・AppKit・Core Audio）

  • Wi-Fi のほか USB ケーブルでも接続できる

経緯

3 つのやり方を経て

  1. 2026.10.10Wine 版

    Wine・DXVK・MoltenVK で Alyx が Vision Pro に。約 30 fps

  2. 2026.10.11ネイティブ ARM 版

    Valve の Linux ARM64 版 Alyx を macOS で直接。メニュー 60 fps

  3. 2026.10.12vxrt を書き始める

    Wine が限界だったので、Windows ランタイムをゼロから

  4. 2026.10.14vxrt で Alyx をプレイ

    Vision Pro の中で、ステージの切り替えとセーブを越えて

  5. 2026.10.16ALVR へ

    Quest や Pico へ配信する道

  6. 2026.10.17音・IPD・振動・USB

    光る描画の不具合も修正。自前の翻訳器で The Lab が動く
